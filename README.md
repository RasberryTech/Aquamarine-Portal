# Aquamarine-Portal
Aquamarine's Wii U user interface.

## How to clone this and make your own Aquamarine:
Step 1: Use Node.js v24.11.0 and MySQL 26.7 because that's what I used.

Step 2: Use npm start when you have cloned the repo.

Step 3: If you have any issues then please use npm install or add a new thread on the issues tab built in to Github.
